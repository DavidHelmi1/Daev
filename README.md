# David Helmi Bahari: Portfolio

Static site (HTML + CSS + vanilla JS). No build step, no backend.

## Before publishing
1. Put your CV at `assets/David-Helmi-Bahari-CV.pdf` (the "Download CV" button points there).
2. Optional: set `EMAIL` near the top of the `<script>` in `index.html` to show your email in the Contact section. Left empty, it shows "Available via LinkedIn message".

## Deploy to GitHub Pages
1. Create a repo (for `https://<username>.github.io`, name it `<username>.github.io`).
2. Upload `index.html` and the `assets/` folder to the repo root.
3. Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)` > Save.
4. Your site goes live in about a minute. Use that URL in your CV.

The hero status panel (uptime, etc.) is a labelled visual simulation, not real data.
